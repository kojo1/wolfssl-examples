The examples demostrate simple key agreement with ECDH between Alice and Bob. 

- ecdh-ecpoint

This example exchanges the public keys with raw ecpoint format.

- ecdh-x963

This example exchanges the public keys with X9.63 format.

You can build and run the example as follows.

```sh
$ cd ecdh-ecpoint or ecdh-x963
$ make
$ ./ecdh
```
